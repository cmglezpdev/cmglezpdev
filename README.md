# Hi, I'm Carlos Manuel

I'm a Cuban software engineer based in Mexico, working remotely. I build backend services, payment systems, and full-stack SaaS products, and more and more AI apps built around agents. I have 5 years of experience and a B.Sc. in Computer Science from the University of Havana.

Right now I'm at AOShield Solutions, building healthcare software for a Canadian client with C#, .NET Core, React, and Azure. Before that I spent three years at Dara Services, where I went from backend engineer to technical lead of a multi-tenant platform built with NestJS and React.

I write about system design, software architecture, and AI engineering, with my own numbers when I have them.

## Experience

- **Dara Services**, Technical Lead (Jan 2026 to Sep 2026). I led a new multi-tenant agency platform, a NestJS and React modular monolith. I started out coordinating five developers and took over the full-stack work as the team got smaller. I built AI agents with the Vercel AI SDK, attribute-based permissions that the API and the agent tools share, and observability with Grafana, Prometheus, and Loki.
